# Aries Codex Skills Pack

This pack contains Codex skills for Aries - Budget Management.

## Structure

```text
AGENTS.md
.codex/
└── skills/
    ├── core-data-viewmodel/
    ├── ui-navigation-compose/
    ├── add-edit-validation-import-export/
    ├── statistics-settings-about-qa/
    ├── firebase-api-v2/
    └── git-team-workflow/
```

Each folder contains one `SKILL.md`.

## Usage

Copy into the repository root if you want Codex to use it locally.

If the team does not want AI folders in GitHub, keep `.codex/` local and add it to `.gitignore`:

```gitignore
.codex/
.cursor/
.ai/
```
